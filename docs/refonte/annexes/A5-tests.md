# A5 — Tests : contrats du dépôt, tests à mettre à jour, tests à ajouter

## 1. Commandes (dépôt)

```bash
npm test -- --run              # vitest : tests unitaires, une seule passe (`npm test` seul reste en mode veille dans un terminal interactif) ; aucun test ne doit être supprimé sans équivalent
npm run check                    # svelte-check : 0 erreur
npm run lint                     # eslint (interdit {@html}, vérifie le registre d'icônes via un test)
npm run build
PLAYWRIGHT_HTML_OPEN=never npx playwright test <fichier>   # un fichier e2e (le serveur de test se construit seul : ports 4173, 4174, 4175 libres)
E2E_EXIGER_BACKEND=1 PLAYWRIGHT_HTML_OPEN=never npm run test:e2e   # tout, backend allumé : un test sauté devient un échec
```
**Agent non interactif** : le reporter `html` de `playwright.config.ts` ouvre un serveur local à la première erreur et bloque le terminal tant qu'on ne l'arrête pas ; `PLAYWRIGHT_HTML_OPEN=never` (ou `--reporter=list`) l'évite. Dans tout le dossier, « `npx playwright test …` » s'entend avec cette variable.
Projets Playwright (`playwright.config.ts`) : `chromium` (suite habituelle, bureau), `responsif` (6 tailles : 360×740, 390×844, 740×360, 768×1024, 1024×768, 1440×900), `monochrome` (21 pages × 390×844 et 1440×900 × clair/sombre, états ouverts compris ; `CAPTURES_DIR=<dossier>` dépose des captures), `redimensionnement` (1 920 → 320 px sans recharger ; cibles de 44 px). Chaque test part d'un navigateur où le profil **citoyen** est déjà choisi (`storageState`) ; `persona.spec.ts` part d'un navigateur vide. L'API est doublée : `tests/e2e/doublure-de-l-api.mjs` + `tests/e2e/doublures.ts` (la recherche est rendue par le serveur : `page.route` ne la voit pas).
